# 1.0.6.4_LocPluginTest

Fork of LocalizedStringPlugin to export strings to ParaTranz with usage and ID searching and a tagging system.

## About

This project is started at 2024/04/01, for the experiment [Project GW Simplified Chinese](https://gw2.shoushou1106.org/zhcn). It is used to export localized string from Frosty to [ParaTranz](https://paratranz.cn/projects/9739). With the release of [zyf722/flamethrower](https://github.com/zyf722/flamethrower) contains more comprehensive feature, and the future plan of a open source modding community of Project GW Simplified Chinese, this project was discontinued and repurposed to [Frosty v1 Localization Experience](https://github.com/users/shoushou1106/projects/3), as part of [LocalizedStringStudioPlugin](https://github.com/shoushou1106/LocalizedStringStudioPlugin_FrostyV1).

See also: [ParaTranz2FrostyLoc](https://github.com/shoushou1106/ParaTranz2FrostyLoc)

## Features
- Export JSON for ParaTranz
- ID extract based on original usage searching.
- Button to batch convert Traditional Chinese into Simplified Chinese.
- Tagging system based on path pattern matching.
